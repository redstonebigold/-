# 优学院课程自动播放脚本 — 使用说明

## 一、这是什么

一个「篡改猴（Tampermonkey）」用户脚本，在优学院（`www.ulearning.cn`）课程学习页自动运行：

1. 自动识别当前小节是否已完成（看目录栏对勾）
2. 未完成则自动播放视频（倍速交给 Global Speed 插件控制）
3. 播放结束后自动点「下一页」
4. 章节结束弹出「继续下一章」时自动点击
5. 全部章节跑完后自动停止

## 二、安装步骤

1. 确认浏览器已安装 **Tampermonkey（篡改猴）** 扩展。
2. 点击篡改猴图标 → **管理面板 / 新建脚本**。
3. 清空内容，把 `优学院自动播放.user.js` 的**全部代码**粘贴进去。
4. `Ctrl + S` 保存。
5. 打开优学院课程页（`www.ulearning.cn`），右上角会出现**悬浮控制面板**。

## 三、使用方法

- 点悬浮面板的 **「▶ 开始」** 开始自动播放。
- 点 **「⏹ 停止」** 随时停止。
- 脚本默认**不会自动开始**，需要手动点开始（更安全，避免误触）。

## 四、关于倍速

脚本**不主动修改播放倍速**，完全交给 **Global Speed** 插件控制。请确保：
- Global Speed 已在浏览器启用；
- 若用 Global Speed 调速，视频进度以实际播放为准，脚本通过「已播完时长 ≈ 总时长」判断结束，与倍速无关。

## 五、如果脚本没反应 / 定位不准

脚本所有可调项都集中在文件顶部的 `CONFIG` 里。常见排查：

1. **打开控制台看日志**：按 `F12` → Console，找 `[优学院自动播放]` 开头的日志。
2. **对勾识别不准**：核心依据是目录项 `.page-name` 上的 `complete` class 和 `<i class="iconfont finish">` 图标。若平台改版，检查目录项 HTML 里完成态的实际 class，更新 `doneKeywords`。
3. **「下一页」按钮找不到**：脚本会兜底「直接点击目录栏下一项」，通常无需按钮也能翻页。
4. **视频在 iframe 里无法访问**：若播放器是跨域 iframe，脚本无法读取视频状态，此时依赖「已看完」绿色标记兜底判断。

## 六、注意事项

- 请**合理使用**，控制运行频率，避免对平台造成异常压力。
- 脚本仅在本机浏览器运行，不涉及账号密码，不修改平台数据（只做正常的学习操作）。
- 若平台检测到异常行为，请停止使用。
